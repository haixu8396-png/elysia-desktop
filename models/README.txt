# Live2D 模型说明

模型现在保存在「用户数据目录」里（应用内点侧栏「📂 数据目录」按钮即可打开），
升级 / 重装 / 移动应用都不会丢失。

在应用内：⚙ 设置 → 🎀 Live2D 模型设置 → 从文件夹导入 / 从网址加载。
或手动把模型文件夹（含 *.model3.json 或 *.model.json）放进数据目录下的 models/ 文件夹，重启应用即可。

示例结构：

    models/
      haru/
        haru_greeter_t03.model3.json
        haru_greeter_t03.moc3
        textures/...
